# UI 佈局優化說明 (v2.2)

## ? 問題已解決

### 1. 元件重疊問題
**原始問題**:
- lblCpuPercent 和 TextBox1 位置相同 (20, 110)
- 兩個元件疊在一起，無法正常顯示

**解決方案**:
- lblCpuPercent 放大為 150x90，字型 28pt
- TextBox1 設為 Visible=False（保留備用）
- 只顯示一個主要元件，無重疊

### 2. 功能分類不清
**原始問題**:
- GroupBox2 混合 CPU 監測和 EEPROM 功能
- 使用者難以快速找到對應功能

**解決方案**:
- 分成三個獨立 GroupBox
  - GroupBox1: 連線管理（淺青色）
  - GroupBox2: CPU 監測（淺橘色）
  - GroupBox3: EEPROM 寫入（淺粉色）
