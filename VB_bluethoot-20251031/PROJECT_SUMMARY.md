## ?? 技術規格

### 通訊協定
- **BaudRate**: 9600
- **Data Bits**: 8
- **Parity**: None
- **Stop Bits**: One
- **Timeout**: 5000ms (Read/Write)

### BLE 封包格式
```
SOF(0xAA) + CMD + LEN + Payload + Checksum + EOF(0x55)
```

#### 支援指令
1. **CMD 0x01** - WS2812 顏色控制
   - Payload: [Percent][R][G][B]
   
2. **CMD 0x02** - EEPROM 寫入
   - Payload: [DecimalValue]

### CPU 顏色映射
```
0-50%:   綠色 RGB(0, 255, 0)
51-84%:  黃色 RGB(255, 255, 0)
85-100%: 紅色 RGB(255, 0, 0)
```
