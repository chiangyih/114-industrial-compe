### 主要功能

#### 1. 藍芽序列埠連線管理 ??
- 自動掃描可用的 COM Port
- 支援藍芽裝置連線/斷線
- 即時偵測裝置連線狀態
- 自動重新整理序列埠清單

#### 2. CPU 使用率監測 ??
- 即時監測本機 CPU 使用率
- 每秒更新一次數據
- 視覺化顏色顯示（綠/黃/紅）
- 支援未連線狀態下的本機監測
- 連線時自動傳送資料到裝置

#### 3. EEPROM 資料寫入 ??
- 支援 4 位元二進位輸入
- 自動格式驗證
- 轉換為十進位後寫入
- 完整的錯誤處理

#### 4. WS2812 LED 控制 ??
- 根據 CPU 使用率自動變色
- 支援 RGB 全彩控制
- 即時顏色同步顯示

## ?? 快速開始

### 系統需求

#### 硬體需求
- Windows 電腦（Windows 7 以上）
- 藍芽模組（HC-05/HC-06 或相容模組）
- Arduino 或相容微控制器（選配）
- WS2812 LED 燈條（選配）

#### 軟體需求
- Visual Studio 2015 或更新版本
- .NET Framework 4.x
- 藍芽驅動程式

### 第一次使用

#### 步驟 1: 硬體準備
```
1. 將藍芽模組與電腦配對
   - 開啟 Windows 藍芽設定
   - 搜尋藍芽裝置
   - 配對成功後會建立虛擬 COM Port

2. 確認 COM Port 號碼
   - 開啟「裝置管理員」
   - 找到「連接埠 (COM 和 LPT)」
   - 記下藍芽模組的 COM Port 號碼（例如：COM5）
```

#### 步驟 2: 啟動程式
```
1. 執行程式（20240828.exe）
2. 表單標題會顯示：
   「113 學年度 工業類科學生技藝競賽 電腦修護職種 
    台中高工 第二站 崗位號碼：24」
```

#### 步驟 3: 建立連線
```
1. 在「連線管理」區域：
   - 從下拉選單選擇藍芽對應的 COM Port
   - 點擊 [OPEN] 按鈕
   
2. 連線成功後：
   - 狀態會從紅色「Disconnect」變為綠色「Connected」
   - 時間開始更新顯示
   - EEPROM 寫入功能啟用
```

#### 步驟 4: 開始監測 CPU
```
1. 在「CPU Loading 監測」區域：
   - 點擊 [Start] 按鈕
   
2. 觀察顯示：
   - CPU 百分比每秒更新
   - 顏色方塊根據使用率變色：
     ? 綠色：0-50%
  ? 黃色：51-84%
 ? 紅色：85%以上
```

## ?? 功能詳解

### 1. 連線管理功能

#### 介面元件

```
┌─────────────────────────────┐
│ 連線管理 (Device Connect)  │
├─────────────────────────────┤
│ [COM5    ▼]     [OPEN]      │
│        [Close]     │
│                  │
│ Device Status : Connected   │
│               (綠底白字)  │
└─────────────────────────────┘
```

#### 操作說明

##### OPEN 按鈕
- **功能**: 開啟序列埠連線
- **條件**: 必須先選擇 COM Port
- **成功**: 狀態變為綠色「Connected」
- **失敗**: 顯示錯誤訊息「連線失敗」

##### Close 按鈕
- **功能**: 關閉序列埠連線
- **效果**: 
  - 狀態變為紅色「Disconnect」
  - 時間顯示停止
  - EEPROM 功能禁用
  - CPU 監測繼續（v2.4新功能）

##### 隱藏功能
- **點擊狀態標籤**: 重新整理 COM Port 清單

#### 連線狀態說明

| 狀態 | 顯示 | 背景色 | 說明 |
|------|------|--------|------|
| 未連線 | Disconnect | 紅色 | 尚未建立連線或連線已中斷 |
| 已連線 | Connected | 綠色 | 序列埠連線正常 |

### 3. EEPROM 寫入功能

#### 介面元件

```
┌────────────────────────────────────┐
│ EEPROM 寫入     │
├────────────────────────────────────┤
│ 請輸入 4 位二進位 (0 或 1)：       │
│          │
│ [ 1010 ]  [ Write ]        │
└────────────────────────────────────┘
```

#### 操作說明

##### 輸入格式
- **長度**: 必須是 4 個字元
- **字元**: 只能是 '0' 或 '1'
- **範圍**: 0000 - 1111 (十進位 0-15)

##### Write 按鈕
- **功能**: 寫入資料到 EEPROM
- **條件**: 必須先建立連線
- **流程**:
  1. 驗證輸入格式
  2. 轉換為十進位
  3. 發送封包到裝置
  4. 顯示結果訊息

#### 輸入範例

| 二進位輸入 | 十進位值 | 說明 |
|-----------|---------|------|
| 0000 | 0 | 最小值 |
| 0101 | 5 | 範例值 |
| 1010 | 10 | 範例值 |
| 1111 | 15 | 最大值 |

#### 錯誤處理

**格式錯誤範例**:
```
輸入: "123"  → 錯誤：長度不足
輸入: "01012" → 錯誤：長度過長
輸入: "01a1" → 錯誤：包含非 0/1 字元
輸入: "0 10" → 錯誤：包含空格

錯誤時會：
1. 清空輸入框
2. 顯示訊息：「Not BIN Format - 請輸入 4 位二進位數字 (0 或 1)」
```

### 4. 時間顯示功能

#### 顯示格式
```
Current Time : 2025/1/15 下午 03:45:30
```

#### 更新機制
- **連線時**: 每秒更新一次
- **未連線**: 顯示 "Current Time :"

## ?? 通訊協定

### 封包格式說明

#### 通用封包結構
```
┌───────┬───────┬───────┬─────────┬──────────┬───────┐
│  SOF  │  CMD  │  LEN  │ PAYLOAD │ CHECKSUM │  EOF  │
└───────┴───────┴───────┴─────────┴──────────┴───────┘
  1 byte  1 byte  1 byte   n bytes   1 byte   1 byte
```

#### 欄位說明

| 欄位 | 大小 | 說明 |
|------|------|------|
| SOF | 1 byte | 封包起始符號，固定為 0xAA |
| CMD | 1 byte | 命令碼，定義封包功能 |
| LEN | 1 byte | 資料長度（PAYLOAD 的位元組數） |
| PAYLOAD | n bytes | 實際資料內容 |
| CHECKSUM | 1 byte | 檢查碼 = (CMD + LEN + PAYLOAD 總和) AND 0xFF |
| EOF | 1 byte | 封包結束符號，固定為 0x55 |

### 命令碼定義

#### CMD 0x01 - WS2812 LED 顏色控制

**用途**: 控制 WS2812 LED 燈條顏色

**封包格式**:
```
┌─────┬─────┬─────┬─────────┬───┬───┬───┬──────────┬─────┐
│ 0xAA│ 0x01│ 0x04│ Percent │ R │ G │ B │ Checksum │ 0x55│
└─────┴─────┴─────┴─────────┴───┴───┴───┴──────────┴─────┘
```

**PAYLOAD 說明**:
| 位元組 | 名稱 | 範圍 | 說明 |
|-------|------|------|------|
| 0 | Percent | 0-100 | CPU 使用率百分比 |
| 1 | R | 0-255 | 紅色亮度 |
| 2 | G | 0-255 | 綠色亮度 |
| 3 | B | 0-255 | 藍色亮度 |

**範例**:
```
CPU 75%, 黃色 (255, 255, 0)
封包: AA 01 04 4B FF FF 00 4F 55
      │  │  │  │  │  │  │  │  └─ EOF (0x55)
      │  │  ││  │  │  │  └──── Checksum (0x4F)
      │  │  │  │  │  │  └─────── B = 0 (0x00)
      │  │  │  │  │  └────────── G = 255 (0xFF)
      │  │  │  │  └───────────── R = 255 (0xFF)
    │  │  │  └──────────────── Percent = 75 (0x4B)
      │  │  └─────────────────── LEN = 4 (0x04)
      │  └────────────────────── CMD = 1 (0x01)
      └───────────────────────── SOF (0xAA)

Checksum 計算:
  0x01 + 0x04 + 0x4B + 0xFF + 0xFF + 0x00 = 0x24F
  0x24F AND 0xFF = 0x4F
```

#### CMD 0x02 - EEPROM 寫入

**用途**: 寫入資料到 EEPROM

**封包格式**:
```
┌─────┬─────┬─────┬───────┬──────────┬─────┐
│ 0xAA│ 0x02│ 0x01│ Value │ Checksum │ 0x55│
└─────┴─────┴─────┴───────┴──────────┴─────┘
```

**PAYLOAD 說明**:
| 位元組 | 名稱 | 範圍 | 說明 |
|-------|------|------|------|
| 0 | Value | 0-15 | 要寫入的十進位數值 |

**範例**:
```
寫入二進位 1010 (十進位 10)
封包: AA 02 01 0A 0D 55
  │  │  │  │  │  └─ EOF (0x55)
      │  │  │  │  └──── Checksum (0x0D)
      │  │  │  └─────── Value = 10 (0x0A)
      │  │  └────────── LEN = 1 (0x01)
   │  └───────────── CMD = 2 (0x02)
      └──────────────── SOF (0xAA)

Checksum 計算:
  0x02 + 0x01 + 0x0A = 0x0D
  0x0D AND 0xFF = 0x0D
```

### 檢查碼計算說明

```visualbasic
' 檢查碼計算公式
Checksum = (CMD + LEN + PAYLOAD所有位元組總和) AND 0xFF

' VB.NET 實作範例
Dim checksum As Byte = CByte((cmd + len + data1 + data2 + ...) And &HFF)
```

## ? 常見問題

### 連線問題

#### Q1: 找不到 COM Port？
```
解決方法：
1. 確認藍芽已配對
   - 開啟 Windows 藍芽設定
   - 檢查裝置是否已配對

2. 檢查驅動程式
   - 開啟裝置管理員
   - 查看是否有黃色驚嘆號

3. 重新安裝藍芽驅動
   - 移除藍芽裝置
   - 重新配對

4. 點擊狀態標籤
- 重新整理 COM Port 清單
```

#### Q2: 連線失敗？
```
可能原因：
1. COM Port 已被其他程式佔用
   → 關閉其他序列埠軟體

2. 藍芽模組電源未開啟
   → 檢查硬體電源

3. 波特率不符
   → 確認為 9600 bps

4. 序列埠設定錯誤
   → 確認參數：8N1
```

#### Q3: 連線中斷？
```
處理方式：
1. 程式會自動偵測並顯示「裝置已中斷連線」
2. 檢查藍芽連線狀態
3. 重新點擊 [OPEN] 建立連線

v2.4 改進：
- CPU 監測不受影響，繼續運作
- 只停止資料傳送功能
```

### CPU 監測問題

#### Q4: CPU 使用率顯示 0%？
```
可能原因：
1. 尚未啟動監測
   → 點擊 [Start] 按鈕

2. CPU 計數器初始化失敗
   → 重新啟動程式

3. 權限不足
   → 以系統管理員身分執行
```

#### Q5: CPU 使用率不準確？
```
v2.4 版本已改進：
- 使用 Math.Round() 四捨五入
- 提高數值準確度

檢查方法：
- 開啟工作管理員比對
- 數值應相近（±5% 內正常）
```

#### Q6: 未連線時能否監測 CPU？
```
v2.4 新功能：
? 可以！不需等待連線
? 點擊 [Start] 即可監測
? 連線後自動傳送資料
```

### EEPROM 寫入問題

#### Q7: 無法輸入資料？
```
檢查：
1. 是否已連線？
   → EEPROM 功能需要連線

2. 輸入框是否可用？
   → 連線成功後應為白色可輸入狀態
```

#### Q8: 顯示「Not BIN Format」？
```
輸入要求：
- 長度：必須是 4 個字元
- 字元：只能是 '0' 或 '1'

正確範例：
? 0000, 0101, 1010, 1111

錯誤範例：
? 01 (太短)
? 01012 (太長)
? 01a1 (包含非數字)
? 0 10 (包含空格)
```

### UI 問題

#### Q9: 視窗太小看不清楚？
```
v2.4 新功能：
? 可以拖曳邊框調整大小
? 可以最大化視窗
? 最小尺寸限制 800×450

操作方式：
- 拖曳視窗邊框
- 點擊最大化按鈕
```

#### Q10: 顏色方塊不變色？
```
檢查：
1. 是否已啟動監測？
   → 點擊 [Start] 按鈕

2. CPU 使用率是否變化？
   → 可執行其他程式增加負載

3. 顏色臨界值：
   - 綠色：0-50%
   - 黃色：51-84%
   - 紅色：85%+
```
