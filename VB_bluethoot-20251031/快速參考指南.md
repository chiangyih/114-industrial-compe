- `Form1_Load()` - 表單載入時執行

#### 連線管理
- `OPEN_Click()` - 開啟連線
- `Close_Click()` - 關閉連線

- `SetDisconnectedState()` - 設定為未連線狀態

- `BT_Read_Click()` - 啟動監測（Start 按鈕）

#### EEPROM 寫入
- `BT_Write__Click()` - Write 按鈕點擊
- `ValidateBinaryInput()` - 驗證輸入格式
- `SendEepromWrite()` - 發送 EEPROM 寫入封包

## ?? 通訊協定速查

### WS2812 LED 控制（CMD 0x01）

```
封包格式（9 bytes）:
[0xAA] [0x01] [0x04] [Percent] [R] [G] [B] [Checksum] [0x55]

範例：CPU 75%, 黃色
AA 01 04 4B FF FF 00 4F 55
```

### EEPROM 寫入（CMD 0x02）

```
封包格式（6 bytes）:
[0xAA] [0x02] [0x01] [Value] [Checksum] [0x55]

範例：寫入 1010 (十進位 10)
AA 02 01 0A 0D 55
```

### Checksum 計算

```visualbasic
' 公式
Checksum = (CMD + LEN + 所有資料) AND 0xFF

' 範例（WS2812）
Checksum = (0x01 + 0x04 + 0x4B + 0xFF + 0xFF + 0x00) AND 0xFF
         = 0x24F AND 0xFF
         = 0x4F
```

## ? 快速排除問題

### 連線失敗

```
檢查清單：
□ 藍芽已配對？
□ COM Port 正確？
□ 其他程式佔用？
□ 電源是否開啟？

快速解決：
1. 點擊狀態標籤重新整理
2. 重新選擇 COM Port
3. 再次點擊 OPEN
```

### CPU 顯示錯誤

```
檢查清單：
□ 是否點擊 Start？
□ 計時器是否啟動？
□ 有無錯誤訊息？

快速解決：
1. 點擊 Stop
2. 再點擊 Start
3. 觀察是否更新
```

### EEPROM 格式錯誤

```
輸入規則：
? 長度：4 個字元
? 字元：只能是 0 或 1

正確範例：
? 0000, 0101, 1010, 1111

錯誤範例：
? 01 (太短)
? 012 (包含 2)
? 1 01 (有空格)
```
