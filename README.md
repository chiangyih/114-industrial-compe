# 114工科賽 Arduino 專案

## 專案說明

 114 年度工業類科學生技藝競賽 Arduino 控制程式，整合 TFT 顯示器、NeoPixel LED 燈條、HC-05 藍牙模組，並可透過 Visual Basic 程式進行遠端控制。

---

## 硬體配置

- **主控板**：Arduino Uno (ATmega328P)
- **顯示器**：ST7735 TFT LCD (160×128, 軟體 SPI)
- **LED 燈條**：WS2812B NeoPixel × 8 (Pin 5)
- **藍牙模組**：HC-05 (UART, 9600 baud)
- **輸入**：4 個按鍵 (PORTC: C0-C3)
- **計時器**：Timer1 硬體中斷 (1 秒週期)

---

## 功能模組

### 主選單功能
1. **Time** - 時間相關功能（預留）
2. **BLE** - 藍牙通訊與資料修改
3. **EEPROM** - 10 秒倒數計時與 LED 閃爍
4. **Light** - NeoPixel 燈光效果選擇

### 藍牙通訊功能
- 支援 VB 程式透過 HC-05 進行雙向通訊
- 指令集：LED 亮度、顏色設定、時間設定、模式切換
- 即時事件回報：選單切換、按鍵動作、模式進出

### 2025年11月5日 - Ver 1.0 HC-05 藍牙通訊功能整合

#### 新增功能
- ✅ **序列埠初始化**：在 `setup()` 中加入 `Serial.begin(9600)` 與 `Serial.setTimeout(1000)`

  - `LED<數字>` - 設定 NeoPixel 亮度 (0-255)
  - `COLOR:RRGGBB` - 設定 LED 顏色 (十六進位)
  - `TIME:HH:MM:SS` - 時間設定與顯示
  - `MODE:<0-3>` - 模式查詢
  - `@` - 系統狀態讀取

- ✅ **開機通知**：系統啟動時發送 `READY`、`VERSION:1.0`、`DEVICE:CYIVS_C217`
- ✅ **TFT 除錯顯示**：接收到的 VB 指令顯示在螢幕 Y=110px 位置（藍綠色）

#### 按鍵事件回報
- ✅ **主選單切換**：Key0/Key1 按下時發送 `MENU_CHANGE:<選單名稱>`
- ✅ **BLE 模式進出**：進入/離開時發送 `ENTER:BLE_MODE` / `EXIT:BLE_MODE`
- ✅ **BLE 子選單操作**：發送 `KEY:<按鍵編號>,BLE_MENU:<索引>`
- ✅ **BLE 執行動作**：發送 `KEY:2,ACTION:<動作名稱>`
- ✅ **Light 模式切換**：發送 `KEY:<0或1>,LIGHT_MODE:<索引>`

#### 通訊協定
- **鮑率**：9600 bps
- **寫入格式**：`# + 指令 + \n` (VB → Arduino)
- **讀取格式**：`@ + \n` (VB → Arduino)
- **回應格式**：`OK:<詳細資訊>` 或 `ERROR:<錯誤類型>:<說明>`
- **事件格式**：`<事件類型>:<參數>` (Arduino → VB)

## 使用說明

### 上傳程式
```bash
# 編譯並上傳
pio run --target upload

# 開啟序列埠監控
pio device monitor -b 9600
```

### VB 程式連接
1. 開啟 VB 藍牙通訊程式
2. 掃描並選擇 HC-05 的 COM 埠
3. 連線後等待 `READY` 訊息
4. 發送控制指令測試

### 測試指令範例
```vb
' VB 程式中執行
Write_Data("#", "LED100")        ' 設定亮度
Write_Data("#", "COLOR:FF0000")  ' 設定紅色
Write_Data("#", "TIME:14:30:00") ' 設定時間
Read_Data("@")                   ' 讀取狀態
```

## 硬體接線

### HC-05 藍牙模組
```
HC-05      Arduino Uno
────────   ────────────
VCC   →    5V
GND   →    GND
TXD   →    RX (Pin 0)
RXD   →    TX (Pin 1) 【經 1KΩ+2KΩ 分壓至 3.3V】
```

⚠️ **重要**：上傳程式時必須移除 HC-05 的 TX/RX 連線！

### NeoPixel LED 燈條
```
WS2812B    Arduino Uno
────────   ────────────
DIN   →    Pin 5
VCC   →    5V
GND   →    GND
```

### 按鍵配置
- **Key0** (PC0)：選單向下 / 子選單向下
- **Key1** (PC1)：選單向上 / 子選單向上
- **Key2** (PC2)：確認執行
- **Key3** (PC3)：返回 / 退出
